# What is the Cilium Star Wars Demo?

The **Cilium Star Wars demo** is an interactive example showcasing Cilium's capabilities in **service discovery, load balancing, and security enforcement** within a Kubernetes cluster. The demo represents a **microservices-based** setup where Star Wars characters themed pods act as individual services communicating with each other.

---

## Key Takeaways from the Demo:
- **Service Discovery**: Each Star Wars character is deployed as a microservice in Kubernetes.
- **Network Policies**: Define and enforce rules on which characters (services) communicate.
- **Observability with Hubble**: Monitor and visualize real-time traffic flows between services.

This demo provides an engaging way to explore how Cilium manages **secure, observable, and efficient networking** within Kubernetes, all while using a fun theme.
