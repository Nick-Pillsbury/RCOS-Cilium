# Week Overview

This project involves setting up a multi-cluster Kubernetes environment using Cilium’s ClusterMesh while enforcing network policies. We are transitioning from stateless pods to stateful applications like MySQL or Redis.


---
## What We Are Trying to Do / Learn

### Multi-Cluster Communication
- Learn how to connect multiple Kubernetes clusters using Cilium’s ClusterMesh.

### Network Policy Enforcement
- Understand how to create and enforce network policies to control pod traffic.
- We learned some of this in the demo and in the first deployment.

### Stateful Workloads
- Gain experience deploying and managing stateful applications.
- We are no longer using empty pods but real applications.

### Observability / Debugging
- Understand how to monitor and troubleshoot a multi-cluster environment.


---
## Why This is Important

### Security
- Network policies in Cilium enhance security by restricting pod-to-pod communication based on defined rules.

### Real-World Application
- Many enterprises use multi-cluster Kubernetes setups.

- By working on this project, we gain hands-on experience with real-world Kubernetes networking and application deployment.
