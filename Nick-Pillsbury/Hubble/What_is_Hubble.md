# What is Hubble?

Hubble is a **network observability tool** for Kubernetes clusters powered by **Cilium**. It provides real-time monitoring and visibility into:
- **Network flows** between pods and services.
- **DNS requests** and responses.
- **HTTP and gRPC traffic**.
- **Security policies** being enforced.

---

## **Key Features**
- **Real-Time Flow Monitoring:** Visualize traffic between pods, namespaces, and external entities.
- **Policy Enforcement Visibility:** See which network policies allow or block traffic.
- **UI and CLI Support:** Use the Hubble UI or CLI to monitor flows.
- **Deep Network Insights:** Provides detailed flow logs, service maps, and security insights.

---

## **Why Use Hubble?**
- **Troubleshoot Network Issues:** Identify blocked connections and latency problems.
- **Enforce and Verify Policies:** Ensure your network policies are working as intended.
- **Improve Security:** Gain visibility into unauthorized or unexpected traffic.
